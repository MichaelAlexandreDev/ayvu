The bundle's executable was launched once in the graphical session; it emitted
`AYVU_SPIKE_READY` and exited with status 0. This verifies basic startup of the
packaged probe, not visual, keyboard, or screen-reader behavior.

The bundle contains `_internal/PySide6`, `_internal/shiboken6`,
`_internal/python3.14`, and copied platform libraries including X11 and AT-SPI

or `NOTICE` files. This is not a full legal inventory; Qt distribution
obligations and a notices strategy remain unresolved before any distribution.

## Other candidates and manual checks

- **wxPython 4.3.1:** the generated PyPI lock has no Linux x86_64 wheel for this
  host. `uv sync --extra wx --extra packager --locked --offline --no-build`
  reported that the package has no binary distribution. Its source build was
  not attempted, so wx startup and bundle size are unmeasured here.
- **Tkinter:** import failed because `libtk8.6.so` is absent. No OS package was
  installed; Tk startup and bundle size are unmeasured.
- **Accessibility:** Orca and Accerciser are not installed. Keyboard
  navigation, screen-reader announcements, and display scaling were not
  manually tested. Do not treat the Qt launch marker or toolkit documentation
  as a pass for these checks.
- **Other operating systems:** no Windows or macOS run was performed.

The only measured candidate is Qt on this Arch Linux host. This is insufficient
to close issue #124 or accept the ADR; manual accessibility evidence and
platform/product decisions remain open.
